# Состояние тестовой сборки NOLA

Готов тестовый установочный комплект **NOLA 1.4.2-sxfix-preview1**.
Игровая DLL с исправлением передачи сохранений собрана на Windows, проверена
и упакована вместе с официальными файлами NOLA 1.4.2 и русской инструкцией.

- [Скачать установочный комплект](https://github.com/ermolenkom986-lab/nola-coop-build/actions/runs/45013697079/artifacts/14751012324) (нужен вход в GitHub; артефакт хранится до 6 декабря 2026).
- [Успешная сборка DLL](https://github.com/ermolenkom986-lab/nola-coop-build/actions/runs/45012433322).
- [Успешная упаковка и проверка совместимости](https://github.com/ermolenkom986-lab/nola-coop-build/actions/runs/45013697079).

Скачанный артефакт содержит `NOLA-1.4.2-SXFIX-Preview.zip` и файл SHA256.
Распакуйте этот ZIP и откройте `README_FIRST_RU.md`. В нём описаны установка
через `install.bat`, замена одной DLL для уже установленной NOLA 1.4.2,
настройка IP/LAN/VPN, откат и проверка на двух ПК.

`a2b3b4badb18cd1643cce27f417023118d52aa07a988ee4eb87aa487b59e10c6`.

SHA256 новой `main.dll`:
`3d064be35946eca610ea225646fecf405f80b82cfeafa11b774d95e088f25abf`.

## Доступ к зависимости открыт

22 ноября 2026 проверка подтвердила доступ к `EpicGames/UnrealEngine`,
`Re-UE4SS/UEPseudo` и закреплённому коммиту UEPseudo
`38e7171e9e8c4a871ff84765848f0290ca34a44e`: все запросы вернули HTTP 200.
Настроенный secret `UE4SS_READ_TOKEN` работает; пересоздавать его не требуется.

[Успешная повторная проверка](https://github.com/ermolenkom986-lab/nola-coop-build/actions/runs/45008905122/attempts/2).

NOLA v1.4.2 использует RE-UE4SS
`5e627997bf265ae6fc89d23357543d8c8ac05a6f`. Требование доступа к закрытому
подмодулю описано в [официальной инструкции UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/blob/5e627997bf265ae6fc89d23357543d8c8ac05a6f/README.md#build-instructions).

## Что проверено

На Windows Server 2022 с MSVC повторно прошли все 16 сценариев `sxrecv`
и все 8 проверок `sxreq`. Пропущенных проверок нет.

Дополнительно проверены 46 встроенных таблиц, признаки release-сборки,
точки входа мода и все 132 импорта из UE4SS. Все необходимые символы есть
в UE4SS.dll из официального комплекта. Контрольные суммы установщика и архива
сверены. В комплект включены точные исходники коммита, из которого собрана DLL.

Исправление проверяет входящие фрагменты сохранения, подтверждает запись
на диск перед учётом фрагмента и восстанавливает передачу после ошибок записи,
проверки CRC и завершения загрузки. Сетевой формат не изменён.

- Коммит исходников текущей сборки: `f2407aa5215c9530771f4201d616ff7cdd5294d2`.
- [Журнал тестов](https://github.com/ermolenkom986-lab/nola-coop-build/actions/runs/45012433322/job/137177469151).
- Предыдущая проверка того же исправленного кода также прошла в Wine 10.0.

Это проверки кода передачи сохранений. Причина исходного вылета клиента
примерно через 15 минут по журналу хоста не установлена; отсутствие вылетов
в игре ещё не подтверждено.

## Как повторить сборку и упаковку

1. В Actions запустить **Build patched NOLA for Windows** с включённым `build_dll`.
2. Дождаться успешного завершения всех заданий. Сценарий собирает `NolaNative`
   с `S2X_RELEASE=ON` и проверяет встроенные таблицы. Артефакт
   `NOLA-v1.4.2-save-transfer-dll` содержит `main.dll`, журналы и сведения о сборке.
3. Запустить **Package tested NOLA for installation**, указав числовой ID
   успешного запуска сборки. Этот сценарий проверяет происхождение артефакта,
   контрольные суммы, импорты UE4SS и результаты тестов. Затем он заменяет
   DLL в официальном комплекте NOLA 1.4.2 и добавляет соответствующие исходники.
4. Скачать артефакт `NOLA-1.4.2-SXFIX-ready`. В нём будет установочный ZIP,
   его SHA256 и русская инструкция `README_FIRST_RU.md` внутри комплекта.

Исходная NOLA 1.4.2 рассчитана на Steam build 25382007 с DLC Cost of Hope
(см. INSTALL.md). Поддержка других сборок игры этим исправлением не добавлялась.
Для проверки через Radmin оба игрока должны установить одинаковый комплект
и использовать режим IP/LAN/VPN.
